# Контекст проекта

Это обезличенная портфолио-версия автономного браузерного расчёта укладки труб.

- Не добавлять реальные производственные задания, обозначения изделий, сетевые пути или названия работодателя.
- Любые новые исходные данные должны быть явно демонстрационными.
- После изменения расчётов запускать `node tests/validate.js`.
- Не формулировать результаты как подтверждение безопасности перевозки или прочности тары.
